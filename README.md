Tic-Tac-Toe Game 🎮

A simple and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

📌 About the Project

This project is a two-player Tic-Tac-Toe game where players take turns playing as X and O. The game automatically checks for a winner or a draw.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

✨ Features

- Two-player gameplay
- Player X and Player O turns
- Automatic winner detection
- Draw detection
- Restart Game button
- Simple and user-friendly interface
- Responsive design

🎮 How to Play

1. Player X starts the game.
2. Click on an empty box to place your mark.
3. Player O takes the next turn.
4. Continue taking turns.
5. The first player to get three marks in a row wins.
6. If all boxes are filled without a winner, the game ends in a draw.
7. Click Restart Game to start a new game.
